# Banking Platform

Full-stack banking platform built with Java, Spring Boot, Angular and Oracle using a microservices architecture.

## Project status

Initial setup and infrastructure configuration in progress.

## Technology stack

### Backend

- Java 17
- Spring Boot 3.x
- Maven
- Oracle Database

### Frontend

- Angular 22
- TypeScript
- pnpm

### Infrastructure

- Docker
- Docker Compose
- Oracle Database Free

## Repository structure

```text
banking-platform/
├── backend/
├── frontend/
├── infrastructure/
├── docs/
└── .github/
```

## Disclaimer

This project is an educational and portfolio project intended to explore enterprise software architecture, distributed systems and banking-related development practices.

It is not affiliated with any financial institution and is not intended for production banking use.
